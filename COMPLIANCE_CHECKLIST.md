# Production checklist

This source package is a local prototype, not a completed production child service.

Before App Store release, complete current legal/App Store review for the intended age category and markets, including a child-focused DPIA, privacy notices, parental/guardian controls where required, accessibility review, security testing, moderation/safeguarding, backend data minimisation and account deletion flows.

Current prototype choices:

- No behavioural advertising
- No tracking
- No third-party analytics SDKs
- No precise location
- No open text chat
- No points / leaderboards / pay-to-win design
- No real-money purchases
- Friend search is represented using character names rather than real names
- Real multiplayer is not enabled in this local prototype
